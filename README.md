# Student Management System using Flask & MySQL

A simple Student Authentication System built with Flask and MySQL.  
This project includes:

- Student Registration
- Student Login
- Dashboard
- Session Management
- Logout Functionality

---

## Technologies Used

- Python
- Flask
- MySQL
- HTML/CSS
- Flask-MySQLdb
